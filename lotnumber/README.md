# Recovered copies — NOT the originals

On 2026-09-08 the original camera JPEGs in this folder were truncated to 0 bytes
by a `sips` invocation run while preparing the verification page, and the empty
files were then committed.

The files here are 1500px-wide recompressed copies made before the truncation.
They are legible — every lot number and model reads clearly — but they are lower
resolution than what came off the phone.

`20260908_014002.jpg` was a second photograph of the same sheet as
`20260908_013959.jpg`; no separate copy of it survived, so it now holds the same
image.

**If the originals are still on the phone, copy them back over these.**

The transcription taken from these sheets is preserved independently, in the
verification page and in `src/data.ts`.
